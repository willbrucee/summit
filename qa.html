    Fixing an answer

    Edit data/overrides.json and run npm run build. Each prompt id takes three lists:

    {
  "countries-africa": {
    "add": ["Somaliland | Republic of Somaliland"],
    "remove": ["Western Sahara"],
    "alias": { "Ivory Coast": ["Cote dIvoire"] }
  }
}

    Add lines use the same format as the lists: the label, then aliases split by |.
